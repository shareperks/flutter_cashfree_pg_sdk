3. Conversion events to use

The app already sends these events. Marketing must mark them as conversions so campaigns can bid on them.

Business goal Google Ads / GA4 event Meta Events Manager event Recommended?
Install / First open first_open Activate App
fb_mobile_activate_app		 Yes — primary for app installs

Registration (new user completes profile) sign_up Complete Registration
fb_mobile_complete_registration		 Yes
Login (returning user) login Login Optional
Purchase (gift card payment) purchase Purchase Yes — for value / ROAS bidding
Purchase note: When available, purchase events include amount and currency INR. Use them for value-based bidding in Google Ads and Meta.

4. Google Ads — step-by-step

1 Open Google Analytics (GA4)

  1. Go to analytics.google.com and open the SharePerks property linked to Firebase project shareperks-8269f (Measurement ID G-WVB4HMKPXX).
  2. Confirm you can see recent app data under Reports → Realtime after a test install (may take a few minutes).

2 Mark key events in GA4

  1. In GA4 go to Admin → Data display → Events.
  2. Find each event below and turn on Mark as key event:
  • first_open
  • sp_first_open (optional)
  • sign_up
  • login (optional)
  • purchase

3 Link GA4 / Firebase to Google Ads

  1. In Google Ads go to Tools → Data Manager / Linked accounts (or Tools → Setup → Linked accounts).
  2. Link Google Analytics (GA4) / Firebase to your Google Ads account using property G-WVB4HMKPXX.
  3. Allow import of site/app metrics and conversions.

4 Import conversions into Google Ads

  1. In Google Ads go to Goals → Conversions → Summary.
  2. Click New conversion action → Import → Google Analytics 4 properties.
  3. Select and import: first_open, sign_up, purchase (and optionally login / sp_first_open).
  4. Set primary conversions for bidding (recommended primary: first_open for install campaigns; purchase or sign_up for engagement / value campaigns).

5 Create App campaigns

  1. Create a Google Ads App campaign.
  2. Android package: com.shareperks
  3. iOS app: use store URL / Apple ID 6746847398
  4. Choose the imported conversion goals from step 4.

5. Meta Ads — step-by-step

1 Confirm the Meta app

  1. Open Meta for Developers.
  2. Select app ID 1558786092457844.
  3. Under settings, confirm Android package com.shareperks and iOS bundle com.shareperks are added.

2 Connect to Events Manager / Ad Account

  1. Open Meta Events Manager.
  2. Select the SharePerks app (1558786092457844).
  3. Confirm the app is linked to the correct Meta Ad Account (agency access is already granted).

3 Verify events are arriving

  1. Install a release or internal test build of SharePerks.
  2. Open the app, complete OTP login / signup, and (optionally) a test purchase flow.
  3. In Events Manager → Test events / Overview, look for:
    • Activate App
    • Complete Registration
    • Login
    • Purchase

4 Mark conversions

  1. In Events Manager, open each event above.
  2. Set as conversion for your Ad Account.
  3. Recommended for bidding: Activate App, Complete Registration, Purchase.

5 Create Meta App campaigns

  1. In Ads Manager create an App campaign / advantage+ app campaign.
  2. Select app 1558786092457844 / SharePerks.
  3. Choose the conversion events you marked in step 4.
  4. Use the Play Store and App Store URLs from Section 2.

6. How to write campaign links (UTMs)

Always add UTM parameters on landing pages and deep links so reports show which campaign drove the user.

Supported parameters

  • utm_source
  • utm_medium
  • utm_campaign
  • utm_content
  • utm_term
  • gclid
    • (Google click ID — usually added automatically by Google Ads)

Example links

Use caseExample
Web / landing https://shareperks.in/?utm_source=google&utm_medium=cpc&utm_campaign=android_install_q3
Deep link shareperks://home?utm_source=meta&utm_medium=paid&utm_campaign=ios_signup
The app stores these UTM values and attaches them to later events (including sign-up and purchase), so you can see full-funnel performance by campaign.

7. How to verify tracking is working

Google

  1. Install the app from an internal track or Play/TestFlight build.
  2. Open Firebase Console → Analytics → DebugView (or GA4 Realtime).
  3. Confirm you see first_open / app_opened.
  4. Complete signup → look for sign_up.
  5. Complete a purchase → look for purchase.

Meta

  1. Open the same test build.
  2. In Events Manager use Test events.
  3. Confirm Activate App on launch.
  4. Confirm Complete Registration after profile setup.
  5. Confirm Purchase after a successful gift-card payment.
Timing tip: Debug / Test streams show events within seconds. Full standard reports in GA4 and Meta can take 24–48 hours to populate.

8. Consent & privacy (for awareness)

  • Users can turn off Share usage data in the SharePerks Settings screen.
  • When off, Google Consent Mode and Meta advertiser tracking are restricted.
  • No action needed from marketing unless Legal requests a different CMP later.
